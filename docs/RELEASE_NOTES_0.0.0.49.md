# Actor Morpher v0.0.0.49

## 修正

- モデル適用時の装備混在、元の装備への復元、一括装備変更を改善しました。
- Human型ミニオンへの一括装備変更に対応しました。
- 変更したActorのモデル・装備を、フィールド移動やカットシーンでの再生成後も引き継ぐようにしました。
- アカウント切り替え・ログアウト時のActor管理処理を修正しました。
- 適用に必要なモデルデータが不正な項目をモデル検索から除外しました。
- 3Dプレビューの処理負荷を軽減しました。

## 追加・操作改善

- モデル検索から、ゲーム内で現在ターゲットしているActorに適用できます。
- 現在のモデルと装備のピン留め、および一括ピン留め・解除を追加しました。
- Actorの現在装備と一括装備のコピー元を、名前・モデル番号で検索して選択できます。お気に入り登録にも対応しました。
- 装備一覧にフェイスアクセサリーを追加しました。
- 一括装備の染色に自由色のカラーパレットを追加しました。右クリックで染色なしに戻せます。
- Actorの装備は右クリックで外せます。
- 装備選択ウィンドウのサイズ変更、アイコンを含む選択範囲、見出しの表示を改善しました。
- オリジナル装備と変更後の装備を折り畳めるようにしました。
- 一括装備の初期状態を「装備なし」にし、染色なしを空欄のボタンで表示します。

3Dプレビューは引き続き既存のソフトウェア方式です。ゲーム標準のキャラクター描画への切り替えは含みません。
